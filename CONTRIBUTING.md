# Contributing

Thanks for your interest in the video-conference project.

## Development

Requires [pnpm](https://pnpm.io/) (npm or yarn also work).

```bash
pnpm install
pnpm dev
```

Useful checks:

```bash
pnpm lint
pnpm build
```

## Pull requests

1. Branch from `main`.
2. Keep changes focused; match existing Next.js / component layout.
3. Ensure `pnpm lint` and `pnpm build` pass before opening a PR.
4. Open a PR against `main` with a clear description of why the change is
   needed.
